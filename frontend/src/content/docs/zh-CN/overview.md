ApiPilot 是一个 AI 辅助的 API 自动化测试平台。它把 OpenAPI 规格理解、测试计划生成与审批、后端测试执行、Run 结果查看和 PDF 测试报告放进同一个工作台。

> ApiPilot 仍处于 Alpha 阶段。自动化测试和主要用户流程已经存在，但不要把当前版本当作成熟的生产测试平台。

## 适合解决什么问题

- 手动读 OpenAPI，整理接口、参数、认证声明和依赖关系。
- 让模型根据规格生成候选测试计划，再由人审核。
- 由确定性后端执行器真正发送 HTTP 请求、提取运行时变量、运行断言并保存结果。
- 从已结束的 Run 生成真实 PDF，保留可追溯的报告。

## Try Us 与 Learn Us

**Try Us** 进入产品控制台：项目、API Client、AI Test Lab、测试计划、Run 与报告中心。

**Learn Us** 是当前这个文档中心，提供部署、配置和产品使用说明。两个入口不共享页面状态；Learn Us 不会替你创建 Run。

## 当前真正实现的能力

- Guest Session 身份、项目和 API Client。
- OpenAPI 规格分析、测试计划生成、审批和版本化重新生成。
- 多请求 Run 执行、运行时变量、常用断言、SSE 事件、取消和历史查看。
- 终态 Run 的服务端 PDF 生成、数据库保存、报告中心查看/下载/打印。

## 当前不包含

- 独立可视化工作流模块：没有画布、条件分支编排或工作流模板。
- 注册/登录和云端配额。
- 请求/响应正文、headers 和变量值的完整持久化。
- Docker、CI/CD 自动部署。
