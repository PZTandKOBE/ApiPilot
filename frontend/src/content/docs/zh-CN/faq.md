## 独立可视化工作流在哪里？

尚未开发。ApiPilot 当前有测试计划中的 Scenario / Step / Assertion 结构，但没有画布编辑器、条件分支编排、工作流模板或工作流专属版本系统。请不要把计划树当成图形工作流。

## 可以注册/登录吗？

当前是 Guest-first 阶段。注册、登录、官方云端游客配额仍未实现；现有登录界面不是可用的账户系统。

## 生成 PDF 会重新跑测试或调用 AI 吗？

不会。报告只读取已保存的终态 Run detail，生成真实 PDF 字节并保存。它不会重新请求被测 API，也不会重新调用模型。

## 报告包含请求/响应正文吗？

不包含。Run 没有持久化这些正文、headers 或变量值。报告不会伪造它们，也不显示被脱敏的秘密值。

## 支持哪些断言？

当前支持 `status`、`header`、`field` 常用断言；`schema` 断言尚未实现，会被跳过。

## 为什么计划不能直接运行？

未批准的计划不能创建正式 Run。需要在计划详情批准，或检查是否生成的是新版本 `draft`。

## 为什么旧计划还在？

重新生成会新增版本，不覆盖旧计划，也不改变历史 Run。当前版本由最高 version 派生；删除/回滚版本尚未实现。

## 支持 YAML OpenAPI 吗？

当前文档中心和产品流程主要按 JSON OpenAPI 说明。不要假设所有 YAML 特性都已支持；以实际解析结果为准。

## 可以用于生产吗？

不建议。ApiPilot 仍是 Alpha，缺少完整的运行恢复、CI/CD 和更广泛的安全验收。
