## 计划状态

测试计划大致经历：

| 状态 | 含义 |
|---|---|
| `draft` | 已生成，尚未提交审核 |
| `in_review` | 等待人工审核 |
| `approved` | 已批准，可以创建正式 Run |
| `rejected` | 已拒绝 |

**未批准的计划不能执行。** 审批状态不会因为重新生成而自动复制。

## 检查计划

在计划详情中检查：

- 场景和步骤顺序
- 请求方法、路径
- Extract 变量及其来源
- 断言目标、期望值和描述
- 风险级别和版本信息

如果计划不符合预期，可以拒绝；不要直接执行一个未经审核的计划。

## 重新生成与版本

对已有计划，前端提供显式重新生成入口：

- 新计划使用独立 id（例如 `plan_slug_v2`）。
- 旧计划内容保持不变。
- 历史 Run 仍指向它原本使用的计划 id。
- 新计划是 `draft`，需要重新审批。
- 当前版本由最高 version 派生，不覆盖旧版本。

重新生成需要用户明确确认；普通首次生成遇到已有计划时仍会拒绝，避免静默创建重复计划。

## 当前没有的能力

- 删除、归档或回滚计划版本。
- 完整图形化编辑 Scenario/Step/Assertion。
- 独立可视化工作流或条件分支画布。
